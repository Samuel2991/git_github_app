LESSON 02

Essential Git Commands

Learn the Git commands you will use frequently as a developer.

Check Status

git status

Shows the current state of your working directory and staging area.

Add Changes

git add .

Adds changes to the staging area.

Commit Changes

git commit -m "Your message"

Saves the staged changes as a new version.

View History

git log --oneline

Displays a short history of your commits.

Switch Branch

git switch main

Moves you from your current branch to another branch.
