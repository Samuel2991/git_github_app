Introduction to Git

Learn the basic idea behind Git and version control.

What is Git?

Git is a version control system used to track changes made to files in a project.

Why use Git?

Git allows developers to save different versions of their projects and work safely on new features.

Basic Git Workflow

git add . git commit -m "Save changes"
